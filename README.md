# Transcription Helper

A mobile-friendly audio tool for transcribing music by ear.

**Hosted at:** https://richardjs.github.io/transcription-helper

## What it does

Load an audio file or a YouTube video, set a start and end point around a passage, and hit Resume to loop it repeatedly while you work out the notes. Playback speed can be reduced to 0.5× or 0.75×.

A collapsible Pitch Tools panel provides a two-octave reference keyboard (hold a key to sustain a tone) and a microphone pitch detector that identifies sung notes in real time with cents deviation.
